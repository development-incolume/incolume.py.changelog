## Objectives

This API automates the creation of a changelog file using git records, to better manage your projects, following the Keep a Changelog methodology.

## Description

It works by capturing the records of the `git tag -n` command, thus obtaining the date, labels and changes, and then generating a file to manage the relevant changes for each version.

The package includes Quality Assurance (QA) tools such as ruff and mypy, as well as security tools such as bandit, pipaudit and safety.
