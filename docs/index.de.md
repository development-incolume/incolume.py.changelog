## Ziele

Diese API automatisiert die Erstellung einer Changelog-Datei anhand der Git-Aufzeichnungen, um Ihre Projekte besser zu verwalten, und folgt der Keep-a-Changelog-Methodik.

## Beschreibung

Sie funktioniert durch das Erfassen der Aufzeichnungen des Befehls `git tag -n`, wodurch Datum, Labels und Änderungen ermittelt werden, und erzeugt dann eine Datei zur Verwaltung der relevanten Änderungen für jede Version.

Das Paket enthält Qualitätssicherungs-Tools (QA) wie ruff und mypy sowie Sicherheits-Tools wie bandit, pipaudit und safety.
